
# 电商商品价格自动化采集与对比工具

## 项目简介

本工具能够从抖音电商平台批量抓取商品信息，自动清洗去重数据，按价格排序，并提供可视化图表和性价比推荐。

## 功能特点

- ✅ 支持按关键词搜索采集商品
- ✅ 抓取商品名称、价格、销量、店铺评分、网址链接
- ✅ 自动数据清洗与去重
- ✅ 按价格从低到高排序
- ✅ 商品横向对比表格
- ✅ 价格分布直方图
- ✅ 价格-销量关系图表
- ✅ 性价比推荐标注（Top 3）

## 技术栈

- Python 3.10+
- Flask 2.0+
- requests
- matplotlib
- Jinja2

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 命令行工具使用

```bash
# 基本用法
python cli.py -k "耳机"

# 指定采集页数
python cli.py -k "手机" -p 3

# 保存数据到文件
python cli.py -k "笔记本电脑" -s

# 生成可视化图表
python cli.py -k "耳机" -v

# 完整选项
python cli.py -k "关键词" -p 3 -s -v
```

### 启动Web演示服务

```bash
python app.py
```

然后访问 http://localhost:5000

## 性价比计算公式

```
性价比得分 = (店铺评分 / 5) × (log(销量+1) / log(最大销量+1)) / (价格 / 1000)
```
