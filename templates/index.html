📝 Cookie 获取步骤（重要）：

  1. 使用浏览器打开 抖音官网 并登录账号
  2. 按 F12 打开开发者工具
  3. 切换到 Network（网络） 选项卡
  4. 在页面上搜索关键词（如"耳机"）
  5. 在 Filter 输入框输入搜索接口关键词（如 search/item）
  6. 点击任意一个商品相关的 API 请求
  7. 在右侧找到 Headers → cookie，复制整个 Cookie
  8. 同时在 Query String Parameters 中找到 msToken 和 a_bogus 参数并复制

⚠️ 重要：

  • Cookie 必须包含 odin_tt 字段
  • msToken 通常在 Cookie 中或请求参数中
  • a_bogus 是必需的安全签名参数
